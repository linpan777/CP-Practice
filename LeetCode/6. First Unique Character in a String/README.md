# 387. First Unique Character in a String

[LeetCode 題目連結](https://leetcode.com/problems/first-unique-character-in-a-string/)

**難度：** `Easy`
**標籤：** `Hash Table`, `String`, `Counting`

## 📝 題目描述
給定一個只包含小寫英文字母的字串 `s`。
找出字串中**第一個且唯一（不重複）**的字母，並回傳它的索引值。
如果字串中所有字母都重複了，則回傳 `-1`。

## 💡 解題思路

### ✅ 最佳解法：Two-Pass (兩次遍歷) + 陣列降維計數
因為題目保證字串只包含「小寫英文字母」（共 26 個），所以我們捨棄底層運算較慢的 `unordered_map`，直接開一個大小為 26 的 `vector` 陣列來當作計數器，利用 `c - 'a'` 將字母映射到陣列索引，達成效能極致的 $O(1)$ 存取。

1. **第一次遍歷 (建立字元頻率表)：**
   使用 `for(char c: s)` 逛過整個字串，將每個字母對應在陣列中的計數器 `+1`。
2. **第二次遍歷 (按照字串順序抓出目標)：**
   這是此題的核心陷阱！我們必須**再次遍歷原字串 `s`**，而不是去遍歷那 26 格的陣列。
   利用 `for(int i = 0; i < s.size(); i++)` 依序檢查每個字母 `s[i]`，去問陣列「這個字母的總出現次數是多少？」
   第一個被問到次數為 `1` 的字母，就是字串中「最前面」的唯一字元，直接回傳當下的索引值 `i` 即可。若迴圈結束都沒找到，回傳 `-1`。

## ⏱️ 複雜度分析
* **時間複雜度：** $O(n)$
  $n$ 為字串長度。我們剛好將整個字串完整遍歷了兩次（$2n$），常數省略後為 $O(n)$。
* **空間複雜度：** $O(1)$
  無論字串多長，我們永遠只宣告了一個長度固定為 26 的 `vector`，消耗的記憶體空間為常數級別。

## 🎓 學習心得
這題完美整合了前幾題學到的兩大技巧：**「Array as Hash Map (長度 26 陣列計數)」** 與 **「Two-Pass 兩次遍歷邏輯」**。
在實作過程中最深刻的體悟是，釐清了「尋找字串中最前面的唯一字元」時，第二次迴圈的迭代對象必須是**原字串**，才能保證由左至右的順序性。此外，也徹底了解在「鍵值範圍已知且極小」的情境下，使用 `vector` 絕對優於 `unordered_map`。
