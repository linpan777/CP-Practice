# 242. Valid Anagram

**難度：** `Easy`
**標籤：** `String`, `Hash Table`, `Counting`

## 📝 題目描述
給定兩個字串 `s` 和 `t`，請判斷 `t` 是否為 `s` 的字母異位詞 (Anagram)。
換句話說，如果 `s` 和 `t` 包含的字母種類與數量完全相同，只是排列順序不同，則回傳 `true`；否則回傳 `false`。

## 💡 解題思路

### ✅ 最佳解法：使用 Hash Map 計數 (Frequency Counter)
我們可以使用 `unordered_map` 來記錄每個字母出現的「次數」。
1. **長度檢查：** 如果兩個字串長度不同，絕對不可能構成字母異位詞，直接回傳 `false` (Early Return 是一個很好的防呆機制)。
2. **建立計數器：** 遍歷字串 `s`，將出現的字母作為 Key，並把對應的 Value (次數) `+1`。
3. **消耗計數器：** 遍歷字串 `t`，將出現的字母次數 `-1`。
   * 如果在計數器中找不到該字母，代表 `t` 多了奇怪的字母，回傳 `false`。
   * 如果該字母的次數被扣到小於 `0`，代表 `t` 裡面這個字母的數量比 `s` 還多，回傳 `false`。
4. 若順利跑完迴圈，代表所有字母都完美抵銷，回傳 `true`。

## ⏱️ 複雜度分析
* **時間複雜度：** $O(n)$
  只需要將長度為 $n$ 的字串各遍歷一次即可完成計數與檢查。
* **空間複雜度：** $O(1)$
  雖然使用了 Hash Map，但因為英文字母最多只有 26 個（或 ASCII 範圍內的固定字元數），Map 的大小不會隨著輸入字串 $n$ 的長度無限增長，因此視為常數空間。

## ⚠️ 踩坑紀錄與重要觀念 (Key Takeaways)

1. **Map 的自動初始化魔法：**
   在 C++ 中，當我們使用 `compare[c]++` 時，如果 `c` 這個 Key 不存在，Map 會自動幫我們建立這個 Key，並因為 Value 型態是 `int`，會自動將其初始值設為 `0`。這讓我們可以省去 `if` 判斷，直接進行 `++` 運算。
   *(注意：一般函式內的區域變數 `int a;` 不會自動歸零，會有隨機垃圾值，這是 Map 專屬的特性！)*
2. **`erase` 範圍陷阱：**
   如果使用 `multiset` 並想用 `erase` 刪除單一元素，只能傳入單個迭代器如 `erase(find(c))`。若傳入兩個相同的迭代器 `erase(find(c), find(c))`，代表刪除該區間 `[A, A)`，實際上不會刪除任何東西。
