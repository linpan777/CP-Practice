# 1. Two Sum

**難度：** `Easy`
**標籤：** `Array`, `Hash Table`

## 題目描述
給定一個整數陣列 `nums` 和一個目標值 `target`，請在該陣列中找出**和為目標值**的那**兩個**整數，並回傳它們的陣列索引 (Index)。
* 假設每組輸入都只會有一個確切的解答。
* 陣列中同一個元素不能使用兩次。
* 回傳結果的順序不限。

## 解題思路

### 暴力解法 (Brute Force)
最直覺的作法是使用雙層 `for` 迴圈，將每個數字與後面的數字一一配對。
* **時間複雜度：** $O(n^2)$ - 陣列過大時會導致效能極差 (Time Limit Exceeded)。

### 最佳解法：使用 Hash Map (空間換取時間)
為了解決重複尋找的問題，我們可以使用 `unordered_map` 作為「筆記本」來記錄已經看過的數字與其索引。
1. 遍歷陣列中的每一個數字 `nums[i]`。
2. 計算要湊成 `target` 還缺多少，即 `needed = target - nums[i]`。
3. 查閱筆記本 (Hash Map)：
   * 如果 `needed` 已經在筆記本中，代表找到了完美配對，直接回傳兩個數字的索引。
   * 如果不在筆記本中，就把當前的 `nums[i]` 和索引 `i` 存入筆記本，繼續往下找。

## 踩坑紀錄與常見陷阱 (Common Pitfalls)
在實作這題時，初學 C++ STL 容易遇到以下幾個語法與邏輯陷阱：

1. **`map.find()` 的回傳值不是布林值 (Boolean)**
   * ❌ **錯誤直覺：** `if(table.find(key))` 以為找不到會回傳 `false`。
   * ✅ **正確機制：** 在 C++ 中，`find()` 找不到東西時，會回傳一個指向結尾的「迭代器 (Iterator)」，也就是 `map.end()`。因此，必須嚴格寫成 `if(table.find(key) != table.end())` 來判斷「是否找到」。

2. **`map.insert()` 的參數格式要求包裹 (Pair)**
   * ❌ **錯誤寫法：** `table.insert(nums[i], i);`。編譯器會報錯，因為 `insert` 不接受兩個獨立的參數。
   * ✅ **正確寫法：** 必須用 `{}` 將 Key 和 Value 包裝成一個 `pair`，寫成 `table.insert({nums[i], i});`。
   * 💡 **進階建議：** 業界更常使用直覺的中括號語法 `table[nums[i]] = i;` 來取代 `insert()`。

3. **順序極度重要：先檢查，後寫入**
   * 題目規定「同一個元素不能使用兩次」。我們在迴圈中是**先**檢查 `target - nums[i]` 是否在筆記本中，如果沒有，**才**把自己寫進去。
   * 這個順序可以完美避開「自己配對自己」的錯誤。例如當 `nums = [3, 2, 4], target = 6` 時，如果先把 `3` 寫進筆記本再檢查，程式就會誤把 `3 + 3 = 6` 當成答案，導致發生錯誤。
