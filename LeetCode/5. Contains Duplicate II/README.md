# 219. Contains Duplicate II

[LeetCode 題目連結](https://leetcode.com/problems/contains-duplicate-ii/)

**難度：** `Easy`
**標籤：** `Array`, `Hash Table`, `Sliding Window`

## 📝 題目描述
給定一個整數陣列 `nums` 和一個整數 `k`。
請判斷陣列中是否存在兩個 **相同的數字**，且這兩個數字的 **索引值 (位置) 距離不能超過 `k`**（即 `abs(i - j) <= k`）。
如果存在，回傳 `true`；否則回傳 `false`。

## 💡 解題思路

這題有兩種非常經典的優化解法，都是基於「單次遍歷 (One-Pass)」的概念：

### 解法一：使用 Hash Map 記錄「最新位置」
1. 建立一個 `unordered_map`，把**數字**當作 Key，把**它最近一次出現的位置**當作 Value。
2. 遍歷陣列，先查 Map 看看數字是否出現過。如果出現過，計算「現在的位置」與「Map 裡記錄的位置」的距離，若 `<= k` 則配對成功，回傳 `true`。
3. **喜新厭舊原則：** 無論剛才有沒有配對成功，都直接將 Map 裡該數字的位置更新成「現在的最新位置」，這樣才能保證下一次計算距離時是最短的。

### ✅ 最佳解法 (進階)：滑動視窗 Sliding Window + Hash Set
這題其實只在乎「距離 `k` 以內」有沒有重複數字，超過 `k` 的舊數字根本不需要記。我們可以使用 `unordered_set` 來維持一個大小最多為 `k` 的視窗。
1. 遍歷陣列，如果當前數字已經在 Set 裡面，代表在距離 `k` 內找到了重複，直接回傳 `true`。
2. 把當前數字加入 Set (視窗往右擴張)。
3. **踢除過期數字：** 如果加入後 Set 的大小超過了 `k`，就把**最舊的那個數字**踢掉。那個過期數字在原陣列的值就是 `nums[i - k]`。

## ⏱️ 複雜度分析
* **時間複雜度：** $O(n)$
  兩種解法都只需要將陣列遍歷一次。Hash Map 和 Hash Set 的平均查詢與插入時間皆為 $O(1)$。
* **空間複雜度：** 
  * Map 解法：$O(n)$ (最壞情況下所有數字都不同，需存入全部數字)。
  * **Set (滑動視窗) 解法：** $O(k)$ (視窗大小被嚴格限制在 `k` 以內，空間利用率極高，是真正的最佳化)。

## ⚠️ 踩坑紀錄與重要觀念 (Key Takeaways)

1. **`unordered_set` 是一個無序的大背包：**
   在實作滑動視窗移除最舊元素時，初學者常會直覺寫出 `erase(i - k)`，試圖「刪除第幾個」。但 Set 的底層是沒有順序、也沒有索引值 (Index) 的！因此，如果要從 Set 中移除元素，不能傳入位置，必須大聲喊出**該元素真實的數值 (`nums[i - k]`)**，Set 才能透過數值瞬間找到它並抹除。這是一個非常經典的 Index vs Value 認知陷阱。
2. **Map 的自動插入與覆蓋：**
   在 Map 解法中，不需要寫繁瑣的 `if-else` 來區分「存在就更新、不存在就插入」，直接寫 `table[nums[i]] = i;`，C++ 的底層機制就能完美包辦這兩個動作，讓程式碼更洗鍊。
