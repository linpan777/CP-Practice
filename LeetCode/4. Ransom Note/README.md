# 383. Ransom Note

**難度：** `Easy`
**標籤：** `Hash Table`, `String`, `Counting`

## 📝 題目描述
給定兩個字串 `ransomNote` 和 `magazine`。
請判斷是否能利用 `magazine` 裡面的字母，拼湊出 `ransomNote` 這封勒索信。
* `magazine` 裡的每個字母只能被使用一次。
* 兩個字串都只包含小寫英文字母。

## 💡 解題思路

### ✅ 最佳解法：使用陣列進行字元計數 (Array as Hash Map)
這題與 LeetCode #242 (Valid Anagram) 邏輯極為相似。因為題目保證**只有小寫英文字母**，我們可以捨棄較慢的 `unordered_map`，直接開一個大小為 26 的 `vector` 陣列來當作計數器，利用 ASCII 碼特性 (`c - 'a'`) 將字母映射到陣列的 0~25 索引值，達成 $O(1)$ 的極速存取。

1. **建立雜誌字庫：** 遍歷 `magazine`，將出現的字母在對應的陣列格子裡 `+1` (增加庫存)。
2. **扣除勒索信字元：** 遍歷 `ransomNote`，將出現的字母在對應的陣列格子裡 `-1` (消耗庫存)。
3. **透支檢查：** 如果在扣除的當下，發現某個格子的數字 `< 0`，代表 `magazine` 提供的該字母數量不足，立刻回傳 `false`。若整趟順利跑完，則回傳 `true`。

## ⏱️ 複雜度分析
* **時間複雜度：** $O(m + n)$
  假設 $m$ 為 `ransomNote` 的長度，$n$ 為 `magazine` 的長度。我們只需要將兩個字串各自遍歷一次，陣列的存取時間為 $O(1)$。
* **空間複雜度：** $O(1)$
  我們只宣告了一個固定大小為 26 的 `vector`，不管輸入字串多長，消耗的記憶體空間永遠是常數級別。

## 🎓 學習心得
這題完美驗證了之前學過的計數器概念。最大的收穫是學會了「陣列降維」優化：當 Key 的範圍已知且極小（例如只有 26 個小寫字母）時，直接使用 Array 搭配 ASCII 運算 (`c - 'a'`) 會比使用 Hash Map 帶來更極致的效能。
此外，也熟練掌握了 C++ 的前置遞減語法 `if(--count[x] < 0)`，讓程式碼變得更加洗鍊與專業。
