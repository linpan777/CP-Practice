# 125. Valid Palindrome

[LeetCode 題目連結](https://leetcode.com/problems/valid-palindrome/)

**難度：** `Easy`
**標籤：** `Two Pointers`, `String`

## 📝 題目描述
給定一個字串 `s`，請判斷它是否為「迴文 (Palindrome)」。
迴文的定義是：在**移除所有非字母與數字的符號**，並且將**所有大寫字母轉換為小寫**後，字串正著讀和反著讀都完全相同。

## 💡 解題思路

### 解法一：字串過濾與反轉 (String Reversal)
這是人類直覺最容易想到的正規解法，步驟非常清晰：
1. **過濾與轉換：** 遍歷原字串 `s`，利用 C++ `<cctype>` 函式庫中的 `isalnum()` 判斷字元是否為字母或數字。如果是，則用 `tolower()` 將其轉為小寫，並塞入一個新的乾淨字串 `temp` 中。
2. **複製與反轉：** 建立一個新字串 `rev` 並將 `temp` 複製給它。接著使用 `<algorithm>` 中的 `std::reverse()` 將 `rev` 原地顛倒。
3. **比對結果：** 直接比較 `temp == rev`，若相同即為迴文。

## ⏱️ 複雜度分析
* **時間複雜度：** $O(n)$
  $n$ 為字串長度。我們遍歷了一次原字串，接著 `reverse` 也需要花費線性時間，總體時間複雜度為 $O(n)$。
* **空間複雜度：** $O(n)$
  我們宣告了額外的字串 `temp` 與 `rev` 來儲存過濾後的字元。在最壞的情況下（字串全是字母或數字），需要額外消耗與原字串等長的記憶體空間。

## ⚠️ 踩坑紀錄與重要觀念 (Key Takeaways)

1. **處理字元的強大函式庫 `<cctype>`：**
   學會了不須手動寫 `c >= 'a' && c <= 'z'` 來判斷，直接使用 `isalnum(c)` (判斷字母與數字) 與 `tolower(c)` (轉小寫) 讓程式碼更專業且沒有漏洞。
2. **`reserve()` vs `reverse()` 的天壤之別：**
   * `temp.reserve(n)`：意思是「保留」，向系統預支記憶體空間來加速，**不會**改變字串內容。
   * `std::reverse(begin, end)`：這才是真正的「反轉」內容。
3. **`std::reverse()` 是一個原地破壞性演算法：**
   它的回傳值是 `void`，因此**絕對不能**寫成 `if(temp == reverse(...))`。必須先將字串複製一份，將複製品反轉後，再拿兩者進行比較。
