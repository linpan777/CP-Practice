# 1. Two Sum

[LeetCode 連結](https://leetcode.com/problems/two-sum/) | **難度：** `Easy` | **標籤：** `Array`, `Hash Table`

## 📝 題目大意
給定陣列 `nums` 與目標值 `target`，找出**相加等於 `target` 的兩個數字**，並回傳其索引。
*題目保證恰有一組解答，且同一元素不可重複使用。*

## 💡 解法：Hash Map (空間換取時間)
捨棄 $O(n^2)$ 的雙層迴圈暴力解，我們用 `unordered_map` 當作字典，邊逛邊記：
1. **計算差值：** 遍歷陣列，計算湊齊目標所需的數字 `needed = target - nums[i]`。
2. **查閱字典：** 檢查 `needed` 是否已經在字典裡？如果有，代表配對成功，直接回傳兩者索引。
3. **存入字典：** 如果沒有，就把當前數字與索引存入字典 `table[nums[i]] = i`，繼續往下找。

## ⏱️ 複雜度
* **時間複雜度：** $O(n)$。只需遍歷陣列一次，Hash Map 查詢時間為常數級別。
* **空間複雜度：** $O(n)$。最壞情況下需將所有數字存入 Hash Map。

## ⚠️ 避坑指南與核心觀念
1. **`find()` 不是回傳 true/false：** 
   C++ 的 `find()` 找不到東西時會回傳迭代器 `end()`。判斷「是否存在」必須寫成：`if(table.find(needed) != table.end())`。
2. **更直覺的寫入語法：** 
   業界不愛用 `table.insert({key, value})`，直接寫 `table[nums[i]] = i;` 語法更乾淨俐落。
3. **順序極度重要 (先查、後存)：** 
   必須確保「先檢查另一半在不在，不在才把『自己』存進去」。如果先存自己再檢查，遇到 `target=6, nums=[3, ...]` 的測資時，就會發生 `3+3=6` 自己配對自己的致命錯誤。
